How it improves

Try the same task 8 times, then compare

Each try is scored against the group’s average. Better than average: do more of that. Worse: do less.

3 of 8 worked, so the average is 0.375. Done scores 1 − 0.375 = +0.63; missed scores 0 − 0.375 = −0.38.

If all 8 succeed, or all 8 miss, every try equals the average and nothing is learned. This method is called GRPO: each try is judged relative to its group.

The model has a little randomness when it picks words, so 8 tries at the same page come out differently. The ones that beat the group average are made more likely; the rest less likely. GRPO stands for group relative policy optimization: the group is the 8 tries, relative means compared with the group average, and the policy is the model’s way of choosing actions.
