The goal

Teach a small AI model to finish tasks on web pages

The model

Qwen3-VL-4B

A free, downloadable AI model that reads screenshots and text. It has about 4 billion adjustable numbers, small enough to train on one rented graphics card.

The tasks

MiniWoB++

Over 100 tiny web pages, each with one job, like “enter this date and press Submit”. Each page checks by itself whether the job got done.

The browser

A real browser

A normal web browser with no window on screen, driven by a program instead of a hand.

Using software this way, by looking at the screen and then clicking and typing, is called computer use.

A language model is a program that reads and writes text by guessing what comes next. This one can also read pictures. Training means nudging its billions of internal numbers. The goal is simple: make it finish more of these little web tasks.
