Run 2: practice smarter, not longer

It started from run 1’s model and changed three things.

Broader practice

16 new practice tasks

Tasks the run 1 model found neither too easy nor too hard, including the ones it had forgotten.

Skip useless groups

About 4× more learning per round

It kept trying new groups until enough had mixed results. This is called dynamic sampling.

Fewer, bigger rounds

52 rounds instead of 158

Each round took 4 to 7 minutes instead of 1 to 2, in the same 5 hours.

Result: 72.6% on its practice tasks, and every forgotten skill came back.

In run 1, about 3 of every 4 groups of attempts taught nothing, because tasks were already mastered or still hopeless. Run 2 spent its time only on groups it could learn from. Each round trained on about 48 attempts instead of about 13.
