Takeaways

What we learned

Practice where it’s unsure

Tasks it always solves, or never solves, teach nothing.

Test broadly

Run 1 looked great on its own tasks while quietly forgetting others.

Quality beats quantity

Run 2 did a third as many rounds and learned more from each.

Skills carried over only a little

Never-practiced tasks: 63% → 67% → 67%. Practice helped mainly what it practiced.

Cost: run 1 about $26, run 2 about $15, on one rented A100 GPU at $2.19 per hour.

Next steps could include practicing a much wider mix of tasks to improve carry-over, and trying the harder setting where the model clicks by screen position instead of element numbers. Some tasks, like a collapsible menu, barely moved in either run and likely need a different approach.
