How the model acts

Each turn: look, act, see the new page

1 · Look

It gets the task in words, a screenshot, and a numbered list of the page’s boxes and buttons.

Goal: enter 11/15/2026, press Submit
[7] text box
[12] Submit button

2 · Act

It answers with exactly one action, using those numbers.

fill [7] with “11/15/2026”
then: click [12]

3 · New page

The browser does the action and shows the result. This repeats until the task is done.

Task complete
reward = 1

One full attempt, from the first page to the end, is an episode: a few turns, never more than 8.

The numbered list is what makes this learnable quickly: the model picks an element by its number instead of guessing pixel positions. The example episode takes two turns: type the date, then press Submit.
