Tests use pages it never practiced on

Fresh pages

A new version of each task

Every page is built from a number called a seed, which decides details like the date to type. Tests use seeds never seen in practice, so the model can’t memorize answers.

practice: seeds 1000 and up
tests: seeds 0 to 99

Never-practiced tasks

Whole tasks kept aside

Some tasks are never used for practice at all. They show whether skills carry over to new kinds of tasks.

practiced: enter a date
never practiced: a login pop-up

A score like 72% means it finished 72 of every 100 test pages.

This is how we know the model learned a skill and didn't just memorize. Every number in the rest of the deck is a success rate on test pages like these: 50 pages per task, or 100 for never-practiced tasks.
