The catch

Run 1 forgot skills it never practiced

Later tests showed run 1 got worse at tasks the original model already did well. Getting better at some things while losing others is called forgetting.

TaskOriginalAfter run 1After run 2
Guess a number100%18%, down 82100%, back
Fill a two-step form100%52%, down 48100%, back
Choose from a list98%62%, down 3698%, back
Set a number spinner86%52%, down 3496%, back

Run 1 practiced only 10 tasks, and its small check on never-practiced tasks happened to miss these. Run 2 practiced them and won them back.

These four are the worst cases. The task names in the code are guess-number, form-sequence-2, choose-list and use-spinner. The lesson: test broadly, because a narrow test can hide a model getting worse elsewhere.
